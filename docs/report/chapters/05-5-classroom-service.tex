\subsection{مكوّنات الخدمة}

هذه أكبر خدمات النظام حجماً، وتضمّ ثماني عشرة خدمة تطبيقية. ويعرض الشكل~\ref{fig:comp-02} مكوّنات الخدمة وروابطها الخارجية.

\begin{figure}[htbp]
  \centering
  % 1.92:1 — full width is ~35% of the text block, so it places inline.
  \includegraphics[width=\textwidth,height=0.8\textheight,keepaspectratio]{figures/comp-02-classroom.png}
  \caption{مخطط مكوّنات خدمة الفصول الدراسية.}
  \label{fig:comp-02}
\end{figure}

وتظهر المهام الخلفية الدورية منفصلة عن بقية المكوّنات لأنها تعمل على مؤقّتات ولا يستدعيها مكوّن آخر. وتتولّى تصحيح الحالات الشاذّة، كانقطاع اتصال المعلّم في أثناء الجلسة أو انقضاء موعد إغلاق اختبار.

وترتبط الخدمة بمحيطها عبر ثلاثة مسارات:

\begin{enumerate}
  \item \textbf{صندوق الصادر}: تنشر عبره أحداث المجال إلى الناقل.
  \item \textbf{مخزن الملفّات}: تحفظ فيه المواد المرجعية ومخرجات الجلسات، وتُصدر منه روابط موقَّعة محدودة المدّة.
  \item \textbf{عملاء \en{HTTP} داخليون}: تُشغّل بهم الفهرسة في خدمة المعرفة، وتفكيك الغرف في خدمة البث، وتوليد الاختبارات في خدمة المساعد الحيّ.
\end{enumerate}
